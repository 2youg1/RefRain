RefRain · 七套主题

据 2026-07-25 的旧工件重建。五套的纸／墨／印取自工件像素实测，两套按同族逻辑补齐。

取色来源：墨・侘・砂・濤・桦 五套标工件实测，色值直接从 00-full-page.png 采样，落选的 tex／korea／editorial／mag／fresh／haze 已排除，不参与取色。韶・霞 两套工件中无对应画面，标补齐，按其余五套显示出的规律推导。
实测纠正了我三处臆测：㈠ 五套纸色全是暖白（L 0.94–0.96），不是冷色；㈡ 濤是深蓝当墨（#19345c）配暖纸，冷暖对撞才是它的辨识点，另带金 #c39d32 作第二强调；㈢ 砂的墨是苔绿（#404c41）、桦的印是绿（#486b51）——都与按名字的直觉相反。
我补的部分：工件只涉及纸／墨／印三色，深色态、侧栏体系、以及受理／差戻／Agent／引用四个语义色都缺。深色态由浅色锚点推导；侧栏取墨的色相（濤原本就是墨与侧栏同色），因此深色态下侧栏必然跟随变暗——这是你截图里「切换明暗后影响阅读」的病根。
Agent 标识用每套自己的第二强调色，濤是金、桦是暖红，而非七套共用一种紫。
对比度：十四态正文 ≥ 8:1（多数 ≥ 12:1），印色 ≥ 3.9:1，实测值印在每态色板下方。无纯白纸、无纯黑。

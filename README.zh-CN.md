# RefRain

**一个本地写作工作台：Agent 的每一次落笔都是你可以否决的提案，而你的否决本身是数据。**

*[English README](README.md)* · *[下载 Windows 版](https://github.com/kaile9/refrain/releases/latest)*

---

*refrain* 是歌里反复回到的那一句，也是"克制、不去做"。而 *ref* 是你想确认时会去查的东西。这个名字三义并存，因为这件事本身如此：你不断回到正文，你在读完提案之前不轻易点头，而你当时怎么判断的、为什么，日后可以查。

## 你为什么要用它

先说它拒绝做什么。

**它不会写进你的正文。** Agent 产出的是提案，人点击才合并。没有自动接受、没有后台合并、没有 YOLO 模式，也没有任何设置、参数或插件能造出一个。如果你曾让 Agent 跑过一整章，然后花一小时找它悄悄改了什么——这个项目存在的全部理由就在这里。

**它不会向外发一个字节。** 应用进程无出站网络请求。无账号、无遥测、无自动更新、无崩溃上报。每一次模型调用都发生在你自己的 Harness 里、用你自己的凭据。这句话可以用防火墙验证，所以值得这样写出来。

**它不替你算账。** 不显示价格，不做成本预测，不说"你已用掉预算的 40%"。Token 数字原样呈现 Harness 报的值，标注 `actual`、`estimated` 或 `unknown`。Harness 什么都不报时，你看到的是 *unknown*，不是一个看起来很像真的零。

**它不花你没批准的 token。** 没有后台摘要、没有自动上下文补全、没有"贴心"的预取。每一次运行都先出现在一份你确认的清单里，也不会为了替你省钱而悄悄削减。

**它不绑架你的稿子。** 硬盘上的 Markdown 文件，不装这个程序也能读、也能用 git 管。明天把它删掉，稿子分毫不动。

**Agent 全部离线时它照常工作。** 断开所有 Harness，这仍是一个完整的写作程序：打开、编辑、搜索、保存、撤销。

这些拒绝之后剩下的，才是产品：一个能让你看清 Agent 究竟改了什么、可以接受、可以改写、也可以带着理由扔掉的工作台——而那个理由会被记住。

## 账本

你做的每一次裁决——接受、拒绝、改写后接受，以及**为什么**——都被存下来，可检索、可重放。别的工具把裁决当成一次界面事件：你点了接受，理由就蒸发了。留住它能换来三样别处没有的东西。

**回话。** 你的裁决会成为下一次请求的一部分。Agent 知道上一稿为什么被否，用的是你的原话。

**品味。** 累积的裁决是你判断力的样本。不需要训练，只需要检索。

**来历。** 一部完成的作品可以说清：哪一句是你写的，哪一句是 Agent 提的，哪一句是 Agent 提了、你改过的。

编辑器会过时，Harness 一年一换。账本不会。

## 一个入口

没有常驻工具栏。**Ctrl K** 通向所有命令，面板按需打开、按 Esc 退场。留在屏幕上的是正文。

**Ctrl Enter** 进入禅模式：只剩文字与留白，并带打字机滚动——你正在写的那一行会停在屏幕中上部，不会沉到底边。

## 排版

十八项控制：字体、字号、字重、行距、字距、词距、版心、首行缩进、段距、对齐、页边距、基线网格、行号等等。中文与西文字体分开设置，数值可以拖也可以直接填，你系统里装的字体会被列出来并可搜索。

程序内嵌五款 SIL 开放字体协议的字体，所以在任何机器上呈现一致：**Chiron Sung HK** 排中文正文，**Antic Didone** 做标题，**Jost** 与 **Murecho** 用于界面，**Courier Prime** 是等宽。

基线网格的横线精确落在每行文字下方一像素，并且按段落绘制。这听起来像细节，直到你见过另一种做法：画在容器上的网格，只要段距不是行高的整数倍就会逐段漂移，最后线从字的腰上穿过去，像删除线。`scripts/verify-grid.ts` 每次构建都量一遍。

**段落呼吸**会让光标所在段落之外的文字稍稍退后。不是聚焦模式那种全屏遮蔽——写长文时，周围的文字正是你在与之较劲的东西。

## Agent

任何 Harness 都能用。底座是**文件通道**：程序把请求写成 `request.md`，你交给任何东西——终端里的 Agent、网页对话、甚至同事——再把回复贴回 `result.md`。不需要命令，不需要配置，不需要联网。

再往上，**命令适配器**可以自动化任何有命令行入口的 Harness，而 Agent 面板会告诉你它到底连没连上，而不是存下一条命令、让你一小时后才发现填错了。

| Harness | 层级 | 入口 |
|---|---|---|
| Codex | L2 | `codex app-server --stdio` |
| Claude Code | L2 | Agent SDK `query()` |
| Pi | L2 | stdio 上的 RPC |
| Kimi Code | L2 | node-sdk `KimiHarness` |
| Hermes | L1+ | TUI Gateway JSON-RPC |
| 其他任何东西 | L0 | 文件通道 |

## 我改了什么，以及怎么改回去

你的每一处改动都被记成一条可寻址的修改。可以单独撤回其中任意一条而不动其余，也可以整体撤回；还可以给某条改动附上自己的说明，把整份改动账送给 Agent——这样它是对着当前的文本工作，而不是对着它上次看到的版本。

## 安装

从 [Releases](https://github.com/kaile9/refrain/releases/latest) 下载安装包，Windows x64。

装好后打开一个装着 Markdown 的文件夹，或者把文件夹拖进窗口。可以同时打开多个文件夹；也可以只打开单个文件，不必把它的邻居一并收进来。

## 从源码构建

```bash
bun install
bun run gate                    # 格式、类型检查、测试
cd apps/desktop && ./make.sh    # 渲染层、主进程、preload
bun x electron dist/main/main.cjs
```

## 两处来历

**[md2prompt](https://github.com/kaile9/md2prompt)** 验证了要紧的那一半：人应该看清送进模型的是什么、拿回来的是什么。RefRain 把方向反转——正文是不动的那一端，Agent 的产出才是被审阅的东西。

**[apostle-skills](https://github.com/kaile9/apostle-skills)** 给了纪律。`apostle-artifacts-loops` 提供了委托规程：一次性标识符、重试不覆盖、以磁盘工件作为进程之间的会合点。`apostle-constitutio` 提供了双向零信任——Agent 说自己做了什么，从不被当作它真的做了的证据。
